软件简介

Introduction

Micro Tracker 是一个基于 SAM2 (Segment Anything Model 2) 的显微视频对象分割和跟踪工具。本工具采用最新的 SAM2 模型，支持多帧智能标注、实时预览和高级数据筛选功能，可以帮助您对显微视频中的多个对象进行高精度自动分割和跟踪，广泛适用于生物医学研究、材料科学、细胞追踪等显微视频分析场景。

Micro Tracker is a microscopic video object segmentation and tracking tool based on SAM2 (Segment Anything Model 2). Utilizing the latest SAM2 model, it supports multi-frame intelligent annotation, real-time preview, and advanced data filtering. It assists in high-precision automatic segmentation and tracking of multiple objects in microscopic videos, widely suitable for biomedical research, materials science, cell tracking, and other microscopic video analysis scenarios.

基本使用流程

Basic Workflow

  1. 选择输入源：点击"浏览"按钮选择要处理的视频文件或图像序列文件夹。支持常见视频格式（MP4、AVI、MOV、MKV）和图像格式（JPG、PNG、TIFF、BMP）。
  2. 确认模型路径：确保 SAM2 模型路径正确，默认为 models/sam2/checkpoints/sam2.1_hiera_tiny.pt。如需使用其他模型，可从下拉框选择或点击"浏览"按钮选择模型文件。
  3. 设置输出选项：指定输出视频路径和掩码保存目录（可选）。掩码目录用于保存对象分割的二进制掩码，便于后续处理和分析。
  4. 多帧智能标注（推荐）：使用新对象模式标注所有对象的初始位置，使用修正对象模式在关键帧（形变、遮挡等）添加修正标注。系统会自动生成实时预览帮助您验证标注质量。详见标注教程章节。
  5. 开始处理：点击"开始处理"按钮启动视频处理。处理过程中可以实时查看进度和预计完成时间。标注会自动保存到Results文件夹。
  6. 查看结果：处理完成后自动切换到"结果预览"标签页查看处理结果。您可以播放、暂停并浏览处理后的视频，查看分割和跟踪效果。
  7. 筛选数据：切换到"筛选过滤"标签页，对掩膜对象进行高级筛选、分析和数据导出。详见筛选过滤功能章节。
  1. Select Input: Click "Browse" to select the video file or image sequence folder. Supports common video formats (MP4, AVI, MOV, MKV) and image formats (JPG, PNG, TIFF, BMP).
  2. Confirm Model: Ensure the SAM2 model path is correct (default: models/sam2/checkpoints/sam2.1_hiera_tiny.pt). Select from the dropdown or browse for a custom model if needed.
  3. Output Settings: Specify output paths for the result video and mask directory (optional). Masks are binary segmentation images useful for further analysis.
  4. Smart Annotation (Recommended): Use "New Object" mode for initial positions. Use "Refine Object" mode for keyframes (deformations, occlusions). The system generates real-time previews to verify annotation quality. See Annotation Tutorial.
  5. Start Processing: Click "Start Processing". Monitor progress and estimated time. Annotations are automatically saved to the Results folder.
  6. View Results: Automatically switches to the "Result Preview" tab upon completion. Play, pause, and browse the processed video to check segmentation and tracking.
  7. Filter Data: Switch to "Filtering" tab for advanced screening, analysis, and data export. See Filtering Functions.

🎯 标注教程

🎯 Annotation Tutorial

标注是Micro Tracker的核心功能，通过在关键帧标注对象，SAM2能够自动追踪整个视频中的对象运动。本章详细介绍标注的各个方面。

Annotation is the core feature of Micro Tracker. By annotating objects in keyframes, SAM2 can automatically track object movement throughout the video. This section details the annotation process.

3.1 标注模式详解

3.1 Annotation Modes

🆕 新对象模式 (New Object)

🆕 New Object Mode

  • 用途：首次标注一个新的对象
  • 系统行为：自动分配唯一ID和固定颜色
  • 使用时机：通常在第0帧标注对象首次出现的位置
  • 操作：选择"新对象"单选按钮，然后在视频上绘制边界框或添加点击
  • Purpose: Annotating a new object for the first time.
  • System Behavior: Automatically assigns a unique ID and fixed color.
  • When to Use: Usually at frame 0 or where the object first appears.
  • Action: Select "New Object", then draw a bounding box or add clicks on the video.

✏️ 修正对象模式 (Refine Object)

✏️ Refine Object Mode

  • 用途：在关键帧补充已有对象的标注
  • 操作流程：
    1. 选择"修正对象"单选按钮
    2. 从下拉框选择要修正的对象ID
    3. 浏览到需要修正的关键帧
    4. 添加修正标注（使用相同ID和颜色）
  • 视觉反馈：正在修正的对象会以金色虚线高亮显示
  • ⚠️ 重要限制：修正模式下只能使用点击提示，不能绘制边界框（符合SAM2官方最佳实践规范）。切换到修正模式时会自动切换到点击模式，边界框选项会被禁用。
  • 适用场景：
    • 对象形状显著变化
    • 对象被遮挡前后
    • 对象运动方向改变
    • SAM2追踪出现明显偏差
  • Purpose: Supplementing annotation for an existing object at keyframes.
  • Workflow:
    1. Select "Refine Object" radio button.
    2. Select the Object ID from the dropdown.
    3. Navigate to the keyframe needing correction.
    4. Add refinement annotations (uses same ID and color).
  • Visual Feedback: The object being refined is highlighted with a dashed gold line.
  • ⚠️ Important Limit: Only Click Prompts are allowed in Refine Mode (per SAM2 best practices). Bounding box options are disabled automatically.
  • Use Cases: Significant shape changes, occlusions, direction changes, or tracking deviations.

3.2 提示类型详解

3.2 Prompt Types

▢ 边界框模式 (Box)

▢ Bounding Box Mode (Box)

  • 操作方法：按住鼠标左键拖动绘制矩形框
  • 使用技巧：框选对象的完整轮廓
  • 反馈：松开鼠标后自动生成实时预览
  • 限制：仅在新对象模式下可用
  • Action: Drag with left mouse button to draw a rectangle.
  • Tip: Enclose the entire object contour.
  • Feedback: Real-time preview generates upon release.
  • Limit: Available only in New Object mode.

👆 点击模式 (Point)

👆 Click Mode (Point)

  • 左键点击：添加正向区域（🟢 绿色标记），表示"这是对象的一部分"
  • 右键点击：添加负向区域（🔴 红色标记），表示"这不是对象的一部分"
  • 多点标注：可以添加多个点击来精细化分割
  • 实时预览：点击后即时生成预览，可立即验证效果
  • 保存操作：
    • 按 A 键保存临时点击
    • 按 Ctrl+C 清除临时点击
    • 按 Ctrl+S 保存点击并切换到下一帧
  • Left Click: Add positive point (🟢 Green) - "This is part of the object".
  • Right Click: Add negative point (🔴 Red) - "This is NOT part of the object".
  • Multi-point: Add multiple clicks to refine segmentation.
  • Preview: Instant preview after each click.
  • Save Actions:
    • Press A to save temporary clicks.
    • Press Ctrl+C to clear temporary clicks.
    • Press Ctrl+S to save and go to next frame.

⚠️ 提示类型切换注意事项

⚠️ Switching Prompt Types

  • 可以使用 Ctrl+Q 快捷键在边界框模式和点击模式之间切换
  • 修正模式下边界框被禁用，不允许切换到边界框模式
  • 切换帧前记得保存临时点击，否则会丢失
  • Use Ctrl+Q to toggle between Box and Point modes.
  • Box mode is disabled in Refine Object mode.
  • Remember to save temporary clicks before switching frames to avoid data loss.

3.3 标注操作步骤

3.3 Step-by-Step Guide

标注新对象的完整流程

Annotating New Objects

  1. 选择"🆕 新对象"模式
  2. 浏览到对象首次出现的帧（通常是第0帧）
  3. 选择提示类型（边界框或点击模式）
  4. 绘制边界框或添加点击：
    • 边界框：按住鼠标左键并拖动绘制矩形框
    • 点击：左键添加正向点击，右键添加负向点击
  5. 系统自动分配唯一ID和固定颜色
  6. 查看实时预览mask（以半透明彩色覆盖层显示）
  7. 如果点击模式，按 A 键保存临时点击
  8. 重复以上步骤标注其他新对象
  1. Select "🆕 New Object" mode.
  2. Go to the frame where the object first appears (usually frame 0).
  3. Select prompt type (Box or Point).
  4. Draw box or add clicks:
    • Box: Drag left mouse button.
    • Click: Left click for positive, right click for negative.
  5. System assigns a unique ID and color.
  6. Check the real-time preview mask (translucent overlay).
  7. If using points, press A to save.
  8. Repeat for other new objects.

修正对象的完整流程

Refining Objects

  1. 选择"✏️ 修正对象"模式
  2. 从下拉框选择要修正的对象ID
  3. 浏览到需要修正的关键帧（例如形变帧、遮挡前后）
  4. 系统自动切换到点击模式（边界框被禁用）
  5. 正在修正的对象会以金色虚线高亮显示
  6. 添加点击标注（左键=正向，右键=负向）
  7. 查看实时预览，验证修正效果
  8. 按 A 键保存临时点击
  9. 继续浏览到其他关键帧，重复修正操作
  1. Select "✏️ Refine Object" mode.
  2. Select the Object ID from the dropdown.
  3. Navigate to a keyframe needing correction.
  4. System switches to Point mode (Box disabled).
  5. The target object is highlighted in gold.
  6. Add click prompts (Left=Pos, Right=Neg).
  7. Verify with real-time preview.
  8. Press A to save.
  9. Repeat for other keyframes.

👁️ Real-time Preview

✨ 添加标注后自动生成mask预览

✨ Auto-generated mask preview upon annotation

  • 可以立即验证标注质量
  • 半透明彩色蒙版显示分割结果
  • 预览使用对象的固定颜色
  • 如果预览效果不理想，可以添加更多点击来优化

💾 标注保存与导入

💾 Save & Import

  • 自动保存：点击"开始处理"时自动保存
    • 标注文件自动保存到 Results 文件夹

    • 包含边界框、点击、对象注册等完整信息

  • Auto Save: Occurs when clicking "Start Processing".
    • Saved to Results folder.
    • Filename: {input_name}_annotations.json.
    • Prompts to overwrite if exists.
    • Includes boxes, clicks, and object registry.
  • Import: Load from JSON (Right-side "Import" button).
    • Supports legacy formats.
    • Validates data before loading.
    • Useful for restoring sessions.
    • ⚠️ Import overwrites ALL current annotations.

💡 提示：标注列表会在标注操作（添加/删除对象、保存点击）后自动更新，无需手动刷新。

💡 Tip: The annotation list updates automatically after any operation. No manual refresh needed.

3.5 标注最佳实践

3.5 Best Practices

✅ 建议

✅ Recommendations

  1. 第0帧标注：在第0帧标注所有对象的初始位置（使用新对象模式）
  2. 标注数量：每个对象标注5-10个关键帧即可，不宜过多（标注过多可能影响处理性能）
  3. 关键帧选择：在以下情况添加修正标注
    • 对象形状显著变化
    • 对象被遮挡前后
    • 对象运动方向改变
    • SAM2追踪出现明显偏差
  4. 实时验证：使用实时预览验证标注质量，及时调整
  5. 无需手动保存：标注会在开始处理时自动保存，无需手动操作
  1. Frame 0: Annotate initial positions of all objects at Frame 0.
  2. Quantity: 5-10 keyframes per object is usually sufficient. Too many can slow down processing.
  3. Keyframes: Add refinement when:
    • Shape changes significantly.
    • Before/After occlusion.
    • Direction changes.
    • Tracking deviates.
  4. Verify: Use real-time preview to check quality.
  5. Auto-save: No need to manually save; it happens on processing start.

⚠️ 注意事项

⚠️ Cautions

  • 切换帧前记得保存临时点击（按A键）
  • 未保存的临时点击切换帧后会丢失（有警告提示）
  • 标注信息在点击"开始处理"时自动保存
  • 导入标注会覆盖当前所有标注
  • 删除操作不可撤销，请谨慎操作
  • Save temporary clicks (A) before switching frames.
  • Unsaved clicks are lost upon frame switch (warning provided).
  • Annotations save automatically on "Start Processing".
  • Importing overwrites current annotations.
  • Deletion is irreversible.

🎬 视频处理

🎬 Video Processing

🔍 筛选过滤功能

🔍 Filtering Functions

筛选过滤模块是本软件的关键高级功能，提供了对分割轨迹数据的深度分析和筛选能力。以下是详细的使用流程和功能解释。

The filtering module provides in-depth analysis and screening of segmentation trajectory data.

7.1 掩膜图片序列选择

7.1 Mask Sequence Selection

选择包含掩膜图像的文件夹（通常是处理步骤自动生成的）。掩膜图像是8位灰度PNG图片，每个像素值表示对象ID，背景为0。

Select the folder containing mask images (usually generated automatically). Masks are 8-bit grayscale PNGs (Pixel value = ID, Background = 0).

7.2 参数设置理解

7.2 Parameter Settings

  • 帧率 (FPS)：定义每秒帧数，对计算对象速度和时间关系至关重要。例如，如果实际视频以1帧/秒拍摄，应设置为1.0；如果是每20秒一帧，则应设置为0.05。帧率调整会影响瞬时速度的计算，以及时间相关的数据分析。
  • 比例系数 (μm/pixel)：将像素单位转换为实际物理单位的系数。这个值应根据您的显微镜和摄像设置确定。例如，如果1个像素代表2.5微米，则设置为2.5。此系数会影响所有空间测量，包括面积、距离和速度。
  • FPS: Frames per second. Critical for velocity and time calculations. (e.g., set to 0.05 for 1 frame every 20s).
  • Scale (μm/pixel): Conversion factor from pixels to physical units. Determined by microscope settings. Affects area, distance, and speed.

7.3 筛选条件详解

7.3 Filter Conditions

可以设置六种不同的筛选条件：

Six filter conditions are available:

1. 面积区间筛选

1. Area Range

  • 功能：筛选出面积在指定范围内的对象
  • 单位：μm²（平方微米）
  • 应用场景：去除过小的噪点或过大的聚合体/背景残留
  • 工作原理：计算每个对象的像素面积，并乘以比例系数的平方转换为实际面积
  • Function: Filter objects within specific area range.
  • Unit: μm²
  • Use Case: Remove noise or large aggregates.

2. 面积变化率筛选

2. Area Change Rate

  • 功能：当对象面积变化超过阈值时截断其轨迹
  • 取值范围：0到1（比例值），表示小面积/大面积的比值
  • 应用场景：检测对象融合、分裂或跟踪错误
  • 工作原理：计算相邻帧之间面积比（较小值/较大值），低于阈值时判定为显著变化
  • Function: Truncate trajectory if area changes drastically.
  • Range: 0-1 (Ratio of smaller/larger area).
  • Use Case: Detect fusion, fission, or tracking errors.

3. 瞬时速度区间

3. Instantaneous Velocity

  • 功能：根据对象的瞬时移动速度筛选
  • 单位：μm/s（微米每秒）
  • 应用场景：区分不同运动状态的对象，或识别跟踪跳变
  • 工作原理：计算相邻帧之间质心位移除以时间间隔
  • Function: Filter by movement speed between frames.
  • Unit: μm/s
  • Use Case: Distinguish motion states or jumpy tracking.

4. 总位移区间

4. Total Displacement

  • 功能：根据对象从起点到终点的直线距离筛选
  • 单位：μm（微米）
  • 应用场景：区分迁移和非迁移对象
  • 工作原理：计算对象第一帧与最后一帧质心之间的直线距离
  • Function: Filter by straight-line distance from start to end.
  • Unit: μm
  • Use Case: Distinguish migrating from non-migrating objects.

5. 边界截断排除

5. Boundary Exclusion

  • 功能：当对象接触图像边界时，截断其轨迹
  • 应用场景：确保分析的是完整对象，避免部分截断的对象干扰分析
  • 工作原理：检测掩膜像素是否接触图像四边
  • Function: Truncate trajectory if object touches image borders.
  • Use Case: Ensure analysis of complete objects only.

6. 相互最短距离阈值

6. Min Mutual Distance

  • 功能：当两个对象距离小于阈值时截断轨迹
  • 单位：μm（微米）
  • 应用场景：避免对象交互或拥挤状态的干扰
  • 工作原理：计算对象轮廓间的最短距离，低于阈值时截断
  • Function: Truncate if objects get too close to each other.
  • Unit: μm
  • Use Case: Avoid interaction/crowding interference.

7.4 筛选结果理解

7.4 Understanding Results

  • 完全通过：对象的整个轨迹都满足所有筛选条件
  • 部分截断：对象轨迹在某个时间点不满足条件，轨迹被截断但保留有效部分
  • 完全过滤：对象完全不满足筛选条件，或满足条件的帧数不足以形成有效轨迹
  • Passed: Entire trajectory meets all conditions.
  • Truncated: Trajectory cut at point of failure; valid part retained.
  • Filtered: Object completely removed or remaining trajectory is too short.

关于姿态角度 (posture angle) 的理解

About Posture Angle

导出的轨迹数据中的姿态角度是OpenCV的 cv2.fitEllipse 函数直接返回的原始角度值，表示椭圆的方向。这个角度测量的是椭圆宽度方向（可能是长轴或短轴）与水平线的夹角，范围为0-180度。

The exported posture angle is the raw value from OpenCV's cv2.fitEllipse. It measures the angle between the ellipse width (could be major or minor axis) and the horizontal line (0-180 degrees).

注意：在可视化显示中，系统会自动确定哪个是主轴（长轴）并用红色显示，哪个是次轴（短轴）并用蓝色显示。但保存的角度数据始终是 cv2.fitEllipse 的原始返回值，没有经过调整。

Note: In visualization, Red is always Major axis and Blue is Minor. However, the saved data is the raw unadjusted value.

导出的轨迹数据中的姿态角度是OpenCV的 cv2.fitEllipse 函数直接返回的原始角度值，表示椭圆的方向。这个角度测量的是椭圆宽度方向（可能是长轴或短轴）与水平线的夹角，范围为0-180度。

The exported posture angle is the raw value from OpenCV's cv2.fitEllipse, representing ellipse orientation (0-180 degrees).

注意：在可视化显示中，系统会自动确定哪个是主轴（长轴）并用红色显示，哪个是次轴（短轴）并用蓝色显示。但保存的角度数据始终是 cv2.fitEllipse 的原始返回值，没有经过调整。

Note: Visualization automatically distinguishes Major (Red) vs Minor (Blue) axes. Exported data uses the raw return value without adjustment.
